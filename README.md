# Personal Portfolio

This is my personal portfolio website for SWE 363 Assignment 2. It builds on Assignment 1 by adding expandable project details, button transitions, and clearer form feedback.

The website introduces me as a Software Engineering student and presents two projects I have worked on. It uses HTML, CSS, and JavaScript and is designed for desktop, tablet, and mobile screens.

## Sections

The portfolio includes:

- A home section with my name and tagline
- An About Me section
- A Projects section featuring Madar and Cluclip
- A Contact section with my email and a demo form
- A dark and light theme toggle
- Buttons to show and hide project details
- Smooth button color transitions with reduced-motion support
- Visible keyboard focus outlines on project detail buttons

The contact form is a demo and does not send messages. It validates required fields and email format, then shows confirmation without clearing the fields. Editing a field clears the confirmation. To contact me, use the email link on the website.

## Projects

### Madar

Madar is an academic planning web application designed for KFUPM students. It helps students organize their courses, track semesters and GPA, monitor graduation progress, and manage academic tasks in one place.

### Cluclip

Cluclip is a web application that helps users find where a specific image appears within a video. It compares the provided image with video frames to identify the closest matching moment.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` directly in a browser, or use the Live Server extension.
4. Use the navigation links to move between the website sections.

No additional installation is required.

## Responsive Design

The website uses media queries to adjust its layout for different screen sizes. The home section, navigation, project cards, and contact form reorganize on smaller screens to remain readable and easy to use.
