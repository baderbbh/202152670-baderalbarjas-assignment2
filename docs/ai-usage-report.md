# AI Usage Report

## Tool Used and Use Cases

I used ChatGPT as a supporting tool during this assignment. It helped me understand the requirements, organize the work into smaller steps, and review some of my HTML, CSS, and JavaScript choices.

It also provided example suggestions for responsive design, the theme toggle, and documentation. I reviewed these suggestions before applying them to my portfolio.

## Benefits and Challenges

ChatGPT helped me save time when I needed explanations or wanted to check whether my approach was correct. It was particularly helpful when I was working with CSS media queries and JavaScript local storage.

One challenge was that some suggestions included features that were not required. I had to return to the assignment instructions and decide what should actually be included.

## Learning Outcomes

I improved my understanding of semantic HTML, responsive CSS, and basic JavaScript interactions. I learned how media queries adjust a layout for different screen sizes and how local storage can remember a selected theme.

I also learned the importance of testing each feature instead of assuming that a suggestion will work correctly.

## Responsible Use and Modifications

I used ChatGPT for guidance, examples, and feedback. I made the final decisions about the website’s content, colors, projects, and features.

I reviewed the suggestions, tested the website myself, and changed parts that did not match the assignment or my preferences. I also made sure that I understood the code included in the final project.
